# LR-2026-11-27-01 — Pine v6 release delta 2025–2026 (not covered by V3 knowledge base)

- Source: https://www.tradingview.com/pine-script-docs/release-notes/ (retrieved 2026-11-27), plus
  language/conditional-structures (`once`) and concepts/strategies pages, same date.
- Status: DOCUMENTED (official text read). Behavior NOT verified in TradingView runtime (no editor access).
- Gap evidence: V3 sheet `M70-release-notes.md` is a placeholder; grep of the V3 pack finds no mention of
  `aggressor_side`, multiline strings, automatic parentheses, bottom-panel tables or dynamic `for` bounds.
- Superseded: nothing; extends V3 M70.

| Date | Change | Engineering consequence |
|---|---|---|
| 2026-11 | `aggressor_side` (series int) + `aggressor.buy`=1 / `aggressor.sell`=2; na if unknown or TF > 1T | Orderflow features on tick charts only; treat na as "unknown", never as 0. Data-plan/feed dependent. |
| 2026-10 | Inline input alignment: first input of an `inline`+`group` set has the title, the rest use `""` | Drop Unicode-space padding hacks in UI code. |
| 2026-09 | Tables movable to bottom panel; stacked, stretch cells, text copyable | Dashboard layout must not rely on `position` alone; keep tables compact and self-describing. |
| 2026-09 | Any indentation allowed for wrapped code inside `[ ]` | Older "not a multiple of four" rule now only for wrapped code outside `()`/`[]`. |
| 2026-08 | `once` conditional structure: block runs until it executes on a **closed** bar | On realtime bars it can execute on several ticks (rollback resets it each tick) → side effects (`varip`, `log.*`, `alert()`, strategy orders) may repeat. Use `once cond and barstate.isconfirmed` when side effects matter. Cannot return a value. |
| 2026-08 | `array.binary_search*` on UDT arrays via `sort_field` (const int index or const string name) | Array must be sorted ascending by the same field. |
| 2026-07 | `strategy(calc_on_every_history_tick = …)` (named-argument only; Premium/Ultimate); "Bar detalization" replaces Bar Magnifier UI (`use_bar_magnifier` sets default); "Heikin Ashi mode", "Limit order execution" menus | Backtest reports must record Script-execution and Bar-detalization settings; changing them can cause repainting of strategy results (official warning). |
| 2026-07 | Editor auto-parentheses on Enter | Editor convenience only. |
| 2026-04 | Multiline strings `"""…"""` / `'''…'''`; indentation inside is literal | Useful for JSON alert templates; beware literal indentation in payloads. |
| 2026-04 | `array.sort`, `array.sort_indices`, `matrix.sort` accept UDT collections via `sort_field` | Replaces manual index sorting of objects. |
| 2026-01 | `request.footprint(ticks_per_row, va_percent, imbalance_percent)` → `footprint`, plus `footprint.*` / `volume_row.*` | Premium/Ultimate; returns na when unavailable → explicit availability flag required. |
| 2025-12 | Wrapped code inside `( )` may use any indentation incl. multiples of four | Outside parentheses the old rule still applies (official counter-example). |
| 2025-03 | `for` loop `to_num` re-evaluated before every iteration | Mutating the bound inside the loop changes iteration count (v6 migration note). |

Counterexample / scope: plan-dependent features (footprint, history ticks) may be unavailable in a user's account;
code must degrade to na/explicit status instead of failing silently.
