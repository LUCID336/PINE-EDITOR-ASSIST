# L08 — Market structure and pivot timing

**Prerequisites:** L03, L06  
**Instruction route:** `indicator`  
**Sources:** S21, S22, S34 — resolve in `training/SOURCES.md`. Read the version-specific reference for all calls before implementation.

## Task
Detect confirmed swing highs, store last confirmed level, and flag a close crossing above it without backdating the event.

## Acceptance criteria
- Pivot with right=2 becomes observable two bars after candidate.
- No signal before confirmation.
- Separate visual anchor from observation timestamp.

## Adversarial case
Drawing a past marker and treating it as a tradable event on that past bar.
