# L12 — Risk sizing and invalidation

**Prerequisites:** L11  
**Instruction route:** `quant`  
**Sources:** S26, S27, S16 — resolve in `training/SOURCES.md`. Read the version-specific reference for all calls before implementation.

## Task
Implement an illustrative linear-contract position sizing diagnostic, using hypothetical cash risk, stop distance and syminfo.pointvalue. Round down to a user-defined lot step; do not send orders.

## Acceptance criteria
- Risk=100, distance=5, point value=2, step=1 gives 10 units.
- Invalid zero distance or point value means unavailable.
- Explain currency conversion, inverse contracts, min size, fees, gaps and margin.

## Adversarial case
Using percent distance as price units or assuming pointvalue solves every contract.
