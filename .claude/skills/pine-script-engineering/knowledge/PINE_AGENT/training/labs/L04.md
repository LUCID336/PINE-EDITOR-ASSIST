# L04 — Bounded collections

**Prerequisites:** L03  
**Instruction route:** `debug`  
**Sources:** S18, S16, S32 — resolve in `training/SOURCES.md`. Read the version-specific reference for all calls before implementation.

## Task
Store at most N confirmed closes in an array; compute their mean and compare after warm-up to SMA on ordinary nonmissing close data.

## Acceptance criteria
- Array size never exceeds N.
- N=1 and N=3 pass.
- On synthetic closes 10,11,12,11,14 with N=3 final buffer [12,11,14].

## Adversarial case
Reading index zero from an empty collection or unbounded append.
