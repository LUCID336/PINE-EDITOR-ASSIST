# Competency and evidence rubric

For each lab score 0–2 on six dimensions: (1) specification and API evidence, (2) implementation correctness, (3) temporal/data correctness, (4) tests and adverse cases, (5) readability and explainability, (6) reproducibility and honest reporting. 0=absent/wrong, 1=partial, 2=complete and evidenced. Suggested pass >=10/12, no zero, and all mandatory gates below. Scores are operational heuristics, not standardized qualifications.

Mandatory gates: no future leakage; no invented API; no fabricated compile/test status; all applicable acceptance criteria pass; runtime-required labs have official editor compile evidence and applicable live/reload checks. L15 is an experiment-design lab and need not claim real backtests; a real market edge remains unverified. L16 requires end-to-end evidence, not merely a plan. Reviewers must inspect artifact hashes and logs; CLI progress state is not independent certification. `BLOCKED` is valid, `PASS` without evidence is not.

Use a separate reviewer if available. A failed gate reopens affected prerequisites. Stop iterations when all criteria pass or external blocker is recorded. Do not use number of iterations as a quality metric.
