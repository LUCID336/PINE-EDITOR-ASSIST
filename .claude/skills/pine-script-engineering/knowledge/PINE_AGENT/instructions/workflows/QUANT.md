# Quantitative features and strategy validation

Route M34 M38 M39 M41 M61 M64. See RESEARCH.md sections 6–7. Every feature must declare formula, unit, source, observation delay, warmup, invalidation and test. Classify data NATIVE / PROXY / EXTERNAL / MISSING. For market structure, define confirmed pivot and break; FVG and liquidity sweep are heuristics, not observed stops or order books. Use footprint only if supported, check classification and feed; no true L2 inference from OHLCV. For OI and funding verify venue-specific ticker, units and frequency. No feed means missing, not a guessed value.

Hypothesis → predeclared benchmark → chronological train/validation/holdout → costs → robustness/ablation → paper/live comparison. Keep complete trial registry; avoid holdout tuning and selection bias. Entry and exit timing, price vs tick units, point value, lot rounding, gap risk, fee and slippage assumptions, margin/pyramiding, emulator options must be explicit. Track realized net expectancy, drawdown, trade count, exposure and out-of-sample results; report uncertainty. No profitability claim without test evidence. Use NO TRADE when data or validation is insufficient. No live execution implied.
